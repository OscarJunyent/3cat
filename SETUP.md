# 3Cat × Elink - Portal de Formació en IA

## 🎯 Objectius del Projecte

- Portal web per a materials de formació en IA
- Impartida per Elink.cat per a l'àrea d'Enginyeria de 3Cat (CCMA)
- Deploy serverless a Cloudflare Pages
- Responsiu i accessible

```bash

# Desenvolupament local

# Build

# Deploy a Cloudflare Pages (després de configurar wrangler)
npm run deploy
```
